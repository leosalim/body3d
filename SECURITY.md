# Security

body3d runs in the browser and loads only the model files it is pointed at. If you find a way for
a page using it to be attacked — through a crafted model, an activation list, the `embed.html`
`postMessage` interface or the custom element — please report it privately through GitHub:
**Security → Report a vulnerability** on this repository. Do not open a public issue for it.

Reports are answered within a week. Fixes go into the next release and the changelog says what was
fixed once a release is available.
